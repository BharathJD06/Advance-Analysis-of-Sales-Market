## 📌 Project Overview
An advanced analysis of mobile sales market data exploring sales trends, market share, pricing strategies, and performance metrics across multiple dimensions using Tableau visualizations and Excel-based data modeling.

## 🗂️ Files
| File | Description |
|------|-------------|
| Book1.twb | Tableau workbook with interactive dashboards |
| MobileMarket_4sheets.xlsx | Raw mobile market dataset (4 sheets) |
| MobileMarket_4sheets_SaleDate_filled.xlsx | Cleaned dataset with filled sale dates |
| Report.pdf | Full project report with findings |
| Report.docx | Editable report document |

## 🛠️ Tools & Technologies
- **Tableau** — Interactive dashboards & data visualizations
- **Microsoft Excel** — Data cleaning, transformation & modeling

## 📊 Key Analysis
- Sales trend analysis across time periods
- Market share breakdown by brand & segment
- Price vs. performance correlation analysis
- Regional sales distribution & comparison
- KPI tracking: revenue, units sold, growth rate

## 💡 Key Insights
- Identified top-performing market segments driving 60%+ of revenue
- Uncovered seasonal sales patterns for strategic planning
- Analyzed pricing tier distribution and its impact on market positioning
